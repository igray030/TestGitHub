# Print-on-Demand Design Specs & Ideas

## How to Create Designs in Canva (Free)

1. Go to canva.com and create a free account
2. Create a new design: **4500 x 5400 px** (standard t-shirt size)
3. Set background to **transparent** (requires Canva Pro) or solid color
4. Use bold, readable fonts — avoid thin/script fonts for shirts
5. Export as **PNG** with highest quality
6. Upload to Redbubble / TeePublic

**If you don't have Canva Pro (transparent backgrounds):**
- Use a solid dark background with white text, OR
- Use remove.bg (free) to remove backgrounds after export
- Redbubble accepts designs on white/dark backgrounds

## UPLOAD CHECKLIST PER DESIGN

For each design, upload to ALL of these product types:
- [ ] T-shirt (most sales)
- [ ] Hoodie
- [ ] Sticker (high volume, low price)
- [ ] Mug
- [ ] Phone case
- [ ] Tote bag
- [ ] Poster/art print

**Title format:** "[Main Text] - Funny [Niche] Gift - [Audience]"
Example: "It Works On My Machine - Funny Programmer Gift - Software Engineer"

**Tags (use all 15 on Redbubble):**
Include: main topic, audience, humor style, gift occasion, related terms
Example: programmer, software engineer, coding, developer, funny, gift, geek, nerd, computer, tech, IT, code, programming humor, birthday gift, coworker gift
