# 90-Day Income Generation Project

**Goal:** Generate $1,000 in income within 90 days on a $100 budget.

## Strategy: 3 Parallel Income Streams

| Stream | Budget | Target | Platform |
|--------|--------|--------|----------|
| Freelance Services | $0 | $500 | Fiverr, Upwork |
| Print-on-Demand | $30 | $250 | Redbubble, TeePublic |
| Digital Products | $70 | $350 | Gumroad, Etsy |

## Project Files

- **[PLAN.md](PLAN.md)** — Full strategy, revenue targets, daily checklist
- **[WEEK_BY_WEEK.md](WEEK_BY_WEEK.md)** — Detailed weekly action items
- **[tracker.py](tracker.py)** — CLI income/expense tracker with dashboard

## Quick Start: Tracker

```bash
python tracker.py                              # Show dashboard
python tracker.py income freelance 25 "Fiverr data entry gig"
python tracker.py income pod 12 "Redbubble t-shirt sale"
python tracker.py income digital 15 "Etsy budget template"
python tracker.py expense ads 30 "Pinterest promotion"
python tracker.py log                          # View all entries
```
